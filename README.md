# guardiano3/.github

Organisation-wide files for [GuardianO3](https://guardiano3.com): scam-risk
decisions for live customer sessions, delivered as an API.

- [`profile/README.md`](profile/README.md) is the page shown at
  [github.com/guardiano3](https://github.com/guardiano3).
- [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md),
  [`CONTRIBUTING.md`](CONTRIBUTING.md) and
  [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), with the issue and pull-request
  templates in [`.github/`](.github), apply to every GuardianO3 repository that
  doesn't carry its own.

## SDKs
