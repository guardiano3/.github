# Getting help

| You need | Go to |
|---|---|
| Help with your account, API keys, plan or billing | **support@guardiano3.com** |
| A bug or missing feature in an SDK | An issue on that SDK's repository |
| API reference and guides | The developer console at [guardiano3.com](https://guardiano3.com) |
| To report a vulnerability | [SECURITY.md](SECURITY.md); never a public issue |

When you contact us about a failing request, include its **`X-Request-Id`**
response header. It lets us find the request without you sending us anything
sensitive.

**Never send API keys, session audio, transcripts or personal data**, by email or
in an issue.
